# متابعة أسعار أمازون مصر على تليجرام (ببلاش)

السكريبت بيشتغل كل ساعة، وفيه طريقتين للمتابعة بيشتغلوا مع بعض:

### 1. البحث التلقائي (`searches.txt`)
بتكتب كلمات بحث زي `laptop` أو `air fryer`، والسكريبت بيفتح صفحات البحث دي على أمازون مصر ويسجّل سعر **كل منتج** بيلاقيه. كل صفحة فيها حوالي 60 منتج، فالقايمة الافتراضية بتغطي أكتر من ألف منتج.

لو منتج سعره نزل **25% أو أكتر عن سعره المعتاد**، بيبعتلك رسالة على طول. السعر المعتاد هو متوسط آخر الأسعار اللي اتشاف بيها.

ولو أمازون كاتب على المنتج **خصم 50% أو أكتر** (سعر قديم مشطوب)، بيبعتلك برضه، **بس بشرط** إن السعر نزل فعلاً 15% على الأقل عن السعر المعتاد اللي البوت شافه. كده الخصومات الوهمية، اللي السعر فيها ما اتغيرش والسعر المشطوب مجرد رقم عالي، مش بتتبعت.

- **أول تشغيلتين مفيش تنبيهات**، لأن السكريبت لازم يشوف كل منتج مرتين على الأقل قبل ما يقارن. يعني التنبيهات بتبدأ بعد حوالي ساعتين.
- نفس العرض مش بيتبعت مرتين. ولو السعر نزل أكتر بعد كده بيبعتلك تاني.
- أقصى عدد رسايل في المرة الواحدة 15، والأكبر خصم الأول.

### 2. منتجات بعينها (`products.txt`، اختياري)
لو فيه منتج معين بتستناه، حط اللينك بتاعه وجنبه السعر اللي يبسطك. هيبعتلك لو:

- السعر وصل للرقم اللي كتبته أو أقل.
- السعر نزل 10% أو أكتر عن آخر مرة اتشاف فيها.
- السعر بقى أقل سعر من ساعة ما بدأت تتابع المنتج.

### كل تنبيه فيه
- صورة المنتج، والسعر دلوقتي، وسعره المعتاد في آخر 30 يوم.
- 📉 لو ده أقل سعر في آخر 30 يوم.
- 🎟️ السعر بعد الكوبون لو أمازون عامل كوبون.
- ⭐ التقييم وعدد المراجعات (المنتجات اللي تقييمها أقل من 3.5 مش بتتبعت).
- 🏪 البياع: أمازون نفسه ولا بياع خارجي، والشحن من أمازون ولا لأ.
- 📊 لينك تاريخ السعر على "كان بكام".
- زرارين: **🔕 تجاهل المنتج ده** و**👁️ تابعه**.

المنتجات اللي أرخص من 100 جنيه مش بتتبعت. ولو أمازون رفض أغلب الصفحات 3 تشغيلات ورا بعض، بيبعتلك تحذير. وكل يوم الساعة 10 بالليل بيبعتلك ملخص بأحسن عروض اليوم.

### التحكم من تليجرام
ابعت للبوت أي أمر من دول (أو `/help`):

| الأمر | بيعمل إيه |
|---|---|
| `/add لينك 5000` | يتابع منتج لحد ما يوصل للسعر ده (السعر اختياري) |
| `/remove ASIN` | يبطّل يتابع منتج |
| `/search gaming chair 2` | يضيف قسم يدوّر فيه (الرقم = عدد الصفحات) |
| `/unsearch gaming chair` | يشيل قسم |
| `/list` | يوريك كل اللي بيتابعه |
| `/mute 2` | يوقف التنبيهات ساعتين (أو `/mute 30m`) |
| `/unmute` | يرجّع التنبيهات |
| `/channel @اسم_القناة` | ينشر العروض في قناة كمان (ضيف البوت Admin في القناة الأول). `/channel off` يوقفها |
| `/status` | حالة البوت وآخر تشغيلة |

الأوامر والزراير بتشتغل بس والجهاز مفتوح، لأن `bot.py` هو اللي بيرد عليها. ولو مفيش تشغيلة حصلت على الجهاز من 50 دقيقة، `bot.py` بيبعتلك تحذير.

## الخطوة 1: اعمل بوت تليجرام (دقيقتين)

1. افتح تليجرام وابعت لـ **@BotFather** الأمر `/newbot`، واختار اسم للبوت.
2. هيديك **token** شكله كده `123456:ABC-xyz...`. احتفظ بيه ومتديهوش لحد.
3. افتح البوت الجديد وابعتله أي رسالة، زي `hi`.
4. عشان تعرف الـ **chat id** بتاعك، افتح الرابط ده في المتصفح بعد ما تحط الـ token مكان `TOKEN`:
   `https://api.telegram.org/botTOKEN/getUpdates`
   وهتلاقي فيه `"chat":{"id":123456789` والرقم ده هو الـ chat id.

## الخطوة 2: اختار اللي هيتابعه

**الأقسام:** افتح `searches.txt` وعدّل كلمات البحث على الحاجات اللي تهمك. كل سطر فيه كلمة البحث وبعدها عدد الصفحات:

```
laptop 2
air fryer 1
```

الكلمات الإنجليزي بتجيب نتايج أكتر. وخلي مجموع الصفحات في حدود 20 عشان أمازون ما يحظرش.

**منتجات معينة (اختياري):** افتح `products.txt` وحط كل منتج في سطر لوحده:

```
https://www.amazon.eg/dp/B0CVW6ZSLH 600
https://amzn.eu/d/xxxxxxx 1500
B0HKW6B9G8
```

- تقدر تحط لينك من الموقع، أو لينك من زرار المشاركة في الموبايل، أو الـ ASIN لوحده.
- الرقم اللي بعد اللينك هو السعر اللي يبسطك بالجنيه، وتقدر ما تكتبوش.
- خلي عدد المنتجات في حدود 20 أو 30 عشان أمازون ما يحظرش الطلبات.

## الخطوة 3: شغّله على GitHub ببلاش

1. اعمل حساب على [github.com](https://github.com) لو معندكش.
2. اعمل repository جديد واختار **Private** عشان محدش يشوف قايمة منتجاتك.
3. ارفع كل الملفات اللي في الفولدر ده، ومعاها فولدر `.github` (اسمه بيبدأ بنقطة وممكن يكون مستخبي).
4. من **Settings ← Secrets and variables ← Actions ← New repository secret** ضيف اتنين:
   - `TELEGRAM_TOKEN` وقيمته الـ token.
   - `TELEGRAM_CHAT_ID` وقيمته الـ chat id.
5. افتح تبويب **Actions**، واختار **Track prices**، ودوس **Run workflow** عشان تجربه أول مرة.

من هنا ورايح هيشتغل لوحده كل ساعة. وتقدر تضيف منتجات أو تشيلها بإنك تعدّل `products.txt` من موقع GitHub نفسه.

> **ملحوظة:** أول تشغيلتين بيسجّلوا الأسعار بس، وتنبيهات البحث التلقائي بتبدأ من التشغيلة التالتة، يعني بعد حوالي ساعتين.

## لو عايز تشغّله على جهازك بدل GitHub

```bash
pip install -r requirements.txt
```

بعدها حط الـ token والـ chat id في متغيرات البيئة. في PowerShell:

```powershell
$env:TELEGRAM_TOKEN = "الـ token بتاعك"
$env:TELEGRAM_CHAT_ID = "الـ chat id بتاعك"
python tracker.py --test     # يبعتلك رسالة تجربة
python tracker.py            # يشيّك على الأسعار مرة واحدة
```

ولو عايزه يشتغل لوحده على جهازك، استخدم **Task Scheduler** في ويندوز وخليه يشغّل `python tracker.py` كل كام ساعة.

## تعديلات تقدر تعملها

- **عدد مرات التشييك:** في `.github/workflows/track.yml` السطر `cron: "17 * * * *"` معناه كل ساعة. لو أمازون بقى يرفض طلبات كتير، خليه `"17 */2 * * *"` عشان يشيّك كل ساعتين. ما تخليهاش أقل من ساعة.
- **نسبة النزول في البحث التلقائي:** `DISCOVER_DROP: "25"` في نفس الملف (وفي `run-pc.ps1` للتشغيل على الجهاز). لو التنبيهات كتير ارفعها لـ `30` أو `40`، ولو قليلة نزّلها لـ `20`.
- **نسبة النزول للمنتجات المعينة:** `DROP_PERCENT: "10"`.

## مشاكل ممكن تقابلك

- **`blocked by captcha` في الـ log:** أمازون اشتبه في الطلبات. قلل عدد المنتجات أو خلي التشييك أبعد، وغالباً المشكلة بتروح لوحدها في التشغيل اللي بعده.
- **`no price`:** المنتج خلصان أو مفيش بايع ليه دلوقتي.
- **التشغيل التلقائي وقف:** GitHub ممكن يوقف الجدولة لو الـ repository فضل من غير أي نشاط فترة طويلة (حوالي 60 يوم). لو حصل كده، ادخل تبويب **Actions** وفعّله تاني.
- **جالك تنبيه لعرض مش حقيقي:** ساعات أمازون بيعرض في البحث سعر مقاس أو لون أرخص من المنتج نفسه. افتح اللينك واتأكد من السعر قبل ما تشتري.
- **فيه منتج السعر بتاعه غلط:** أمازون ممكن يغيّر شكل الصفحة. ابعتلي لينك المنتج وأنا أظبطلك السكريبت.

> سحب الأسعار بالطريقة دي مخالف لشروط استخدام أمازون. السكريبت معمول عشان الاستخدام الشخصي الخفيف بس، وبيشيّك على كل منتج مرة كل كام ساعة وبيستنى بين كل منتج والتاني.
